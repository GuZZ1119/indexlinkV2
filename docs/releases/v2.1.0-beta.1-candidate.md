# IndexLink v2.1.0-beta.1 release candidate

This document records the prepared local-first Beta boundary. It is not a GitHub Release yet.

## Release boundary

- Single user and local machine only; the HTTP API has no authentication.
- Manual execution journal; no unattended live trading.
- Deterministic strategy formulas and real-history backtests when a supported data provider or exact local cache is available.
- Optional OpenD paper broker and user-provided AI are disabled unless explicitly enabled or invoked.

## Beta hardening

- Plan-local IANA time zones decide each plan's calendar day.
- SQLite backup and restore procedures cover native and Docker installs.
- Non-loopback API binds fail closed unless an explicit container escape hatch is set.
- OpenD paper broker capability defaults to disabled.
- Rust and Web quality gates run in GitHub Actions.
- Data and strategy provenance is separated from code licensing.

## Upgrade notice

Back up the SQLite database before upgrading. Follow the backup and restore guide for native and Docker installations. Existing plans are migrated to the documented compatibility time zone; users should review the stored time zone before relying on the next scheduled date.

## Release blocker

Do not create the `v2.1.0-beta.1` Git tag or GitHub Release until [DATA_LICENSES.md](../../DATA_LICENSES.md) marks every bundled research dataset as redistributable, or the unconfirmed datasets and their derived artifacts are removed from the release source tree. Source attribution alone is not redistribution permission.
