# Push 2：任意标的通用 Formula 回测内核

## 目标

在不读取网络、数据库或券商的纯函数边界内，对调用方提供的复权日线运行 Fixed DCA 与 Formula V1，并为直观视角和专业视角产出同一份真实轨迹与指标。

## 公平比较约束

- 所有策略使用同一标的、数据快照、时间范围、月度投入日、投入金额和 5 bps 买入成本。
- Formula 只读取模拟成交日之前的已收盘数据；成交日收盘价只用于模拟成交，不能进入本次决策证据。
- 对比从所有已选策略都具备完整预热数据的首个计划日开始，不用默认值填补指标，也不让某条策略少投入几个周期。
- 图表使用时间加权财富指数并把共同首点归一化为 100；专业指标同时保留真实投入、期末资产和现金使用率。
- 价格型回测暂不接收需要 VIX 等外部序列的规则，也不接收精确金额动作；这些能力必须先扩展数据集契约，不能静默以 0 替代。

## 输入与输出

`strategy-evaluation::run_dynamic_backtest` 接收规范化 symbol、显示区间、1–28 日的月度执行日、每期金额、包含预热区间的复权日线，以及唯一的策略版本集合。

输出包含：

- 实际共同起止交易日与共同投入次数；
- 每个策略的不可变 ID/version/name；
- 每日归一化轨迹；
- 区间收益、年化收益、XIRR、最大回撤、年化波动率、Sortino、累计投入、累计买入、现金使用率、期末资产和期末现金。

## 非目标

- 本 Push 不下载行情、不决定供应商，也不保存回测结果。
- 不模拟税费、滑点、分红税、零碎股限制或不同市场的最小交易单位。
- 不把结果称为预测，不把单一历史区间作为策略准入结论。

## 验证重点

- 不同策略返回相同长度、相同起点的轨迹与相同外部现金流。
- Formula 预热窗口来自策略声明的指标需求。
- 人为修改模拟成交日价格不会使该价格进入当天决策证据。
- 需要非价格指标的策略显式失败。
