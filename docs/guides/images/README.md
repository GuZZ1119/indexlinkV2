# 教程截图来源与维护

这些 JPEG 是中文图文教程使用的真实浏览器截图，不是 UI mockup 或生成图片。截图基于 `c0396ac` 的本地网页与 Rust API，制作日期为 2026-10-11；只重命名文件，没有修饰界面、金额、状态或日期。

## 演示边界

- 使用独立临时 SQLite、独立 loopback 端口和清空环境的后端，没有读取现有 `.env` 或用户数据库。
- AI、行情与 paper broker 均未配置；没有真实交易、付费 AI 请求或外部行情数据导入。
- 演示计划使用 `fixed_dca@1`、每月 11 日、每期 `100 USD`、冻结时区 `Australia/Sydney`。截图当天为该时区 10 月 11 日，没有修改操作系统时间或历史证据。
- 人工执行演示记录填报 `90 USD`，备注明确说明没有真实交易；另一份演示计划用于验证跳过。记录只用于教程，不应混入用户实际账本。
- 创建、执行记录、跳过、暂停与继续通过实际界面操作；原建议金额保持 `100 USD`。完成后下一评估显示为 11 月 11 日。
- 策略工坊仅展示未保存表单；回测展示真实数据不可用提示；AI 表单密钥为空，保存/验证成功界面未在本次验收。
- 截图不含用户凭据、真实财务信息、私人路径或原始市场数据。项目自身界面与本次截图沿用仓库代码/文档的 MIT 许可；不赋予外部行情或供应商数据额外分发权。
