审查日期：2026-09-23（AEST）

范围：Rust workspace、Vite/React 前端、HTTP/API 暴露面、AI/OpenD 会话配置、依赖锁文件、公开仓库内容。

## 最终结论

V2.1 已达到**本机单用户试用**的安全边界：默认 API 与 Docker host 端口均限制在 `127.0.0.1`，核心计划、真实回测、策略版本、手工执行 journal 和可选 AI 路径有自动化测试。它仍不具备多用户认证，因此不能直接暴露到局域网或公网。

本次收口修复了默认网络暴露、已知运行依赖漏洞、RSS 无界响应、AI 原文日志和 JSON 截断问题；公开上游移除了没有接线的旧页面、旧 Studio、云部署脚本、PostgreSQL 草稿、模板资源和过期 push 文档。被移除文件在维护者本机通过精确 `.gitignore` 保留，不参与公开构建。

## 仍需接受或后续处理的风险

### 本地使用必须遵守

- API 没有登录、token、CSRF 或远程会话认证。只允许 loopback 使用，不要转发端口。
- 本地浏览器到 API 使用 HTTP；这是同机边界，不是公网传输方案。
- OpenD 权限、行情订阅和数据使用条款由用户自己的账户决定。
- 用户自行输入的 AI Key 会发送到所选供应商；IndexLink 只能保证本地不落盘，不能替供应商承诺数据政策。

### 依赖与许可证

- `cargo audit` 仍报告 `rsa 0.9.10 / RUSTSEC-2023-0071`，上游暂无修复。`cargo tree -i rsa` 在支持的 SQLite target 中没有活动依赖路径；这是 Cargo/SQLx 锁文件解析中的未链接包。本版本保留显式记录，不用 allowlist 静默隐藏。
- 研究数据的再分发权不能由 MIT 项目许可证覆盖。FRED/Cboe/Multpl 的来源和条款已写入 `THIRD_PARTY_NOTICES.md`；发布者仍需自行复核。

### 产品与体验

- 策略分析依赖 ECharts，生产 chunk 仍超过 500 kB；属于性能债务，不是计算正确性问题。
- 普通策略的资金周期与指标观察频率仍共用部分调度语义；后续必须拆成两个契约并引入交易所日历。

## 功能审查摘要

- 计划：真实 SQLite 持久化，支持动态 US/HK/SH/SZ 标的、策略精确版本、暂停/继续/删除。
- 目录：Fixed DCA + 20 家族 × 5 参数的 100 个 Formula 版本；个人策略与官方策略同目录但来源清晰。
- 回测：OpenD 真实日线 + SQLite cache，七档区间，统一现金流/交易日/成本，提供净值、买点和专业指标。
- 建议：scheduler 只幂等创建到期建议，不自动下单。
- 执行：用户手工确认的 append-only journal；一条 due 决策只能最终确认一次。
- AI：会话凭据只存内存；QwenCloud/百炼/GPT/Claude/DeepSeek；所有能力用户手动触发且结果有界。
- Broker：仅显式 OpenD paper 模式；页面只读行情配置不会授予 broker 能力。
